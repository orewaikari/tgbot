# Telegram Chat Bot

Многофункциональный асинхронный бот для Telegram-сообществ, ролевых чатов и игр (`aiogram 3` + `SQLite3`).

---

## ⚡ Всё, что работает на полной автоматике

Бот берет на себя всю рутину по управлению чатом и развлечению участников:

1. **Авто-принятие участников и ролевые теги**:
   - Когда пользователь выбирает персонажа MLBB и админы нажимают «Принять», бот **сам одобряет заявку на вступление** в закрытую беседу (`approve_chat_join_request`).
   - Автоматически **устанавливает плашку/тег** с именем персонажа в профиле участника внутри беседы Telegram (`set_chat_member_tag`).
   - Отправляет персонализированное приветствие и делает общий созыв беседы о прибытии нового героя.

2. **Синхронизация списков в инфоканале**:
   - При смене статуса персонажа (занят, свободен, забронирован) бот **на лету редактирует посты** в привязанном информационном Telegram-канале (`sync_info_channel`), поддерживая список ролей актуальным без ручного вмешательства.

3. **Автоматический сбор статистики и экономика**:
   - Через промежуточное ПО (`StatsMiddleware`) бот **перехватывает каждое сообщение** в реальном времени.
   - Без внешних cron-задач обновляет счетчики активности (за день, неделю, месяц, всего) и **начисляет +1 монету** в кошелек за каждое сообщение.

4. **Распознавание речи (STT на лету)**:
   - При отправке любого голосового сообщения или видеокружка бот перехватывает медиафайл, конвертирует его через `ffmpeg` в WAV 16kHz, распознает через `SpeechRecognition` и **автоматически отправляет расшифрованный текст ответом**, сразу очищая временный файл.

5. **Автоматизация ролевых игр**:
   - **Мафия**: Бот сам отсчитывает 45 секунд таймера сбора, асинхронно раздает секретные роли в ЛС, проводит фазы Ночи и Дня, собирает приватные голоса кнопками, высчитывает результаты казни и автоматически распределяет призовой фонд монетами.
   - **Крокодил**: Выбирает IT-слово, высылает ведущему в ЛС, перехватывает варианты участников в чате и автоматически завершает раунд при первом совпадении, выдавая награду.
   - **Викторина**: Выводит вопрос с кнопками и деактивирует их сразу после первого правильного ответа, начисляя монеты победителю.

6. **Анонимные обращения**:
   - Пересылает сообщения пользователей в спец-топик админ-чата, хранит сессию диалога и позволяет админам отвечать напрямую анонимному отправителю.

## 🎮 Главные функции и команды

### 1. Выбор персонажей MLBB / Вход во флуд
* `/start` — Главное меню в ЛС бота:
  * Выбор класса (Ассасин, Боец, Маг, Стрелок, Танк, Поддержка).
  * Выбор свободного героя и отправка заявки администрации.
  * Анонимная связь с админами.

### 2. Модерация и управление правами
* `!мут [10м/2ч/1д]` / `!размут` — Ограничить отправку сообщений.
* `!варн [причина]` / `!разварн` — Выдать предупреждение (авто-кик при 3 варнах).
* `!кик` / `!бан` / `!разбан` — Удаление и блокировка участников.
* `!роль [пользователь] [название]` — Выдача кастомного статуса.
* `!дк [команда] [роль]` — Настройка минимального ранга для доступа к командам (`member`, `moderator`, `administrator`, `creator`).
* `!правила` — Просмотр и установка правил чата.

### 3. Настройка системы регистрации (`/reg_setup`)
* `/reg_setup` — Панель привязки чатов.
* `/reg_set_admin_chat` — Сделать текущий чат админским (сюда идут заявки).
* `/reg_set_private_chat` — Сделать текущий чат приватной беседой участников.
* `/reg_set_channel <id>` — Указать ID канала со списками героев.
* `/reg_add_char <класс> <имя>` / `/reg_del_char <имя>` — Управление списком персонажей.
* `/reg_set_status <имя> <free|occupied|reserved>` — Смена статуса роли вручную.

### 4. Статистика, профили и созывы
* `профиль` / `кто я` — Показать карточку профиля, уровень активности, баланс и брачные данные.
* `топ вся` — Топ участникам по сообщениям и чаю.
* `!неактив 48` — Поиск молчунов, не писавших указанное число часов.
* `созыв` / `!все` — Упоминание всех участников сообщениями по 10 человек.
* `созыв админов` / `!админы` — Вызов администрации.
* `!чистка_базы` — Удалить из БД пользователей, покинувших чат.

### 5. Игры
* `!мафия` — Запустить регистрацию в Мафию.
* `!крокодил` — Запустить «Крокодил» (завершить: `!стоп крокодил`).
* `!викторина` — Вопрос с кнопками вариантов ответа.
* `!казино [ставка]` / `!слоты` — Анимированный игровой автомат.
* `!дартс [ставка]` / `!боулинг [ставка]` — Кубики с анимацией Telegram.

### 6. Экономика, чай и браки
* `заварить чай` — Собрать заварку (раз в 30 минут).
* `попить чай` / `попить чай с сахаром` — Чаепитие (дает бонусы и опыт ролевому браку).
* `кошелек` / `!бонус` — Просмотр монет и ежедневный бонус.
* `магазин` — Покупка заварки, сахара и личного тега в профиль.
* `брак` (ответом) / `согласен` / `развод` / `!забота` — Система бракосочетания и ухода за парой.
* `обнять`, `поцеловать`, `погладить`, `укусить`, `удар` — Ролевые взаимодействия.

## 🛠️ Структура проекта

```text
tgbot/
├── config.py             # Чтение переменных .env
├── database.py           # Запросы к SQLite
├── main.py               # Запуск бота и подключение роутеров
├── utils.py              # Парсеры и проверка прав
├── requirements.txt      # Зависимости Python
├── Dockerfile            # Сборка контейнера
├── docker-compose.yml    # Запуск через Docker Compose
├── middlewares/          # Автоматический перехват активности
│   └── stats_middleware.py
└── handlers/             # Модули команд
    ├── admin.py          # Модерация
    ├── fun.py            # Чай, экономика, браки
    ├── games.py          # Мафия, Крокодил, Казино
    ├── registration.py   # Регистрация MLBB персонажей и анонимки
    ├── stats.py          # Статистика и профили
    ├── stt.py            # Авто-расшифровка голосовых
    ├── whisper.py        # Секретный шёпот
    └── zazyvala.py       # Созывы
```

## 🚀 Быстрый запуск

### 1. Настройка `.env`
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_IDS=123456789
```

### 2. Запуск через Docker Compose (Рекомендуется)
```bash
docker compose up -d
```

### 3. Локальный запуск (Python)
Требуется Python 3.10+ и утилита `ffmpeg` (`sudo pacman -S ffmpeg` / `sudo apt install ffmpeg`).

```bash
pip install -r requirements.txt
python -m tgbot.main
```
